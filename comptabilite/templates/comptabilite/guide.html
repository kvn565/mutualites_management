1. Introduction

Le module Comptabilité & Ventilation permet de gérer l'intégralité de la comptabilité d'une mutuelle de santé :

  • Comptabilité : plan comptable SYSCOHADA, saisie des écritures, validation, rapports (bilan, CPC, balance, grand livre)
  • Ventilation : répartition analytique des écritures par centre de coût et branche d'activité

Ces deux modules fonctionnent ensemble : on saisit d'abord les écritures comptables, puis on les ventile (automatiquement ou manuellement) pour analyser la performance par branche (Maladie, Maternité, etc.) et par antenne/région.

2. Prérequis

Avant de commencer, assurez-vous que :

1
Le plan comptable est initialisé

Un administrateur doit exécuter python manage.py init_plan_comptable pour créer les comptes SYSCOHADA de base (40 comptes).

2
Votre compte a le rôle approprié

Vous devez avoir le rôle Comptable ou Administrateur Mutualité pour accéder aux menus Comptabilité et Ventilation.

3
Les centres analytiques sont créés

Allez dans Comptabilité → Centres analytiques et créez vos antennes, régions, etc.

3. Configurer le plan comptable

1
Accédez au plan comptable

Menu Finance & Comptabilité → Comptabilité → onglet Plan comptable.

2
Vérifiez les comptes existants

Le plan SYSCOHADA de base est préchargé (classe 1 à 8). Vérifiez qu'il contient au moins :

  • 50/521/522/571 — Comptes de trésorerie (Banque, Caisse, Mobile Money)
  • 401 — Fournisseurs
  • 421 — Adhérents / cotisations à recevoir
  • 601 — Prestations médicales
  • 701 — Cotisations des adhérents
3
Ajoutez des comptes si nécessaire

Vous pouvez créer de nouveaux comptes avec le bouton + Nouveau compte.

💡 Conseil : Utilisez les numéros de compte SYSCOHADA (3 chiffres pour les comptes principaux). Par exemple, 601 pour Prestations médicales, 602 pour Frais pharmaceutiques.

4. Saisir des écritures comptables

Une écriture comptable enregistre un mouvement financier sur un compte. Le principe est la partie double : chaque opération génère un débit et un crédit de montant égal.

1
Allez dans "Écritures"

Menu Finance & Comptabilité → Comptabilité → sous-menu Écritures.

2
Cliquez sur "+ Nouvelle écriture"

Remplissez les champs :

  • Date — date de l'opération
  • Pièce comptable — référence (générée automatiquement si vide)
  • Compte — sélectionnez le compte à mouvementer
  • Débit/Crédit — choisissez le sens
  • Montant — en BIF
  • Libellé — description claire de l'opération
  • Statut — laissez "Brouillon" ou passez directement à "Soumis"
3
Exemple : encaissement d'une cotisation

Créez deux écritures avec la même pièce comptable :

CompteDébitCréditLibellé
571 Caisse10 000Encaissement cotisation
701 Cotisations10 000Encaissement cotisation
4
Exemple : paiement d'une prestation médicale
CompteDébitCréditLibellé
601 Prestations médicales25 000Prestation MUT-2024-001
571 Caisse25 000Prestation MUT-2024-001
⚠️ Important : Pour qu'une écriture soit prise en compte dans les rapports (bilan, CPC), elle doit être au statut "Validé". Le workflow complet est : Brouillon → Soumis → Validé/Rejeté.

5. Workflow de validation

1
Soumettre l'écriture

Depuis le détail de l'écriture, cliquez sur 📤 Soumettre pour validation. Le statut passe à "Soumis".

2
Valider ou rejeter

Un comptable superviseur peut ✅ Valider ou ❌ Rejeter l'écriture (avec motif en cas de rejet).

💡 Conseil : Pour une petite structure, vous pouvez directement créer les écritures avec le statut "Validé" si le circuit de validation n'est pas nécessaire.

7. Configurer les règles de ventilation automatique

Les règles permettent de ventiler automatiquement les écritures dès qu'elles sont créées.

1
Accédez aux règles

Menu Ventilations → Règles de ventilation.

2
Créez une règle

Exemple de règle typique :

  • Libellé : "Cotisations — 70% Maladie, 30% Administration"
  • Type d'écriture : Cotisation
  • Centre : (laisser vide = tous les centres)
  • Branche : MAL (Maladie)
  • Pourcentage : 70
  • Priorité : 1

Créez une seconde règle avec branche ADMIN, pourcentage 30, priorité 2.

3
Option "Solde restant"

Si vous cochez cette option, la règle s'applique sur le montant restant après application des autres règles. Utile pour une règle "fourre-tout".

⚠️ Important : Les règles sont appliquées par ordre de priorité. Le total des pourcentages ne doit pas dépasser 100%.

8. Ventiler les écritures

Méthode A — Ventilation automatique
1
Depuis le dashboard Ventilation

Allez dans Ventilations → tableau de bord.

2
Cliquez sur "Auto"

Le bouton Auto applique les règles actives à toutes les écritures validées non encore ventilées.

Méthode B — Ventilation manuelle
1
Créez une ventilation

Nouvelle ventilation et sélectionnez l'écriture, le centre, la branche, le % et le montant.

2
Contrôle de cohérence

Le système vérifie que le total des ventilations d'une même écriture ne dépasse pas 100%. Vous pouvez ventiler une écriture sur plusieurs axes (ex: 60% Maladie + 40% Pharmacie).

3
Validez la ventilation

Depuis le détail, cliquez sur Valider pour rendre la ventilation définitive.

💡 Astuce : Utilisez la ventilation automatique en routine (quotidien/hebdomadaire), et la ventilation manuelle pour les cas particuliers ou les corrections.

9. Budgets et suivi budgétaire

1
Créez un budget

Menu Comptabilité → Budgets → + Nouveau budget. Définissez l'année, le type (annuel/trimestriel/projet) et ajoutez les lignes budgétaires (compte + montant prévu).

2
Suivez l'exécution

Le tableau de bord comptable affiche le taux d'exécution de chaque budget avec une barre de progression colorée (vert ≥ 75%, orange ≥ 50%, rouge < 50%).

3
Rapport budgétaire

Menu Comptabilité → Rapports → type "Suivi budgétaire". Comparez le prévu vs réalisé avec les écarts.

10. Gestion de la trésorerie

1
Prévisions de trésorerie

Menu Comptabilité → Trésorerie. Créez des prévisions d'encaissements et décaissements pour anticiper les besoins de liquidités.

2
Consultez le solde

Le dashboard comptable affiche la trésorerie disponible (somme des soldes des comptes de classe 5).

11. Rapprochement bancaire

1
Créez un rapprochement

Menu Comptabilité → Rapprochements. Sélectionnez le compte bancaire, la période, et saisissez le solde comptable et le solde bancaire.

2
Pointage des lignes

L'admin vous permet de pointer les écritures une par une pour identifier les écarts. Le rapprochement est équilibré quand solde ajusté = solde bancaire.

12. Rapports et clôture d'exercice

Rapports disponibles
1
Bilan comptable

Actif vs Passif à une date donnée. Le bilan présente l'ensemble des comptes de situation.

2
Compte de résultat (CPC)

Charges vs Produits sur une période. Le résultat (bénéfice ou déficit) est calculé automatiquement.

3
Balance des comptes

Tous les comptes avec leurs totaux débit/crédit et solde sur une période.

4
Grand livre & Journal

Détail chronologique de toutes les écritures.

5
Rapport analytique

Menu Ventilations → Rapport. Analyse croisée Centre × Branche des montants ventilés.

Export des données
6
CSV

Tous les rapports et listes peuvent être exportés en CSV (compatible Excel). Utilisez le bouton CSV disponible dans les ventilations.

13. Bonnes pratiques

✅ À faire :
  • Saisir les écritures régulièrement (quotidiennement si possible)
  • Utiliser des libellés clairs (ex: "Cotisation MUT-2024-0123 — Jean KAMILI")
  • Ventiler automatiquement via les règles pour gagner du temps
  • Faire un rapprochement bancaire mensuel
  • Consulter le dashboard comptable chaque semaine
  • Générer le bilan et le CPC en fin de mois
❌ À éviter :
  • Modifier une écriture validée — annulez-la et créez-en une nouvelle
  • Supprimer un compte qui a des écritures — désactivez-le plutôt
  • Ventiler avec un total différent de 100% (le système vous alertera)
  • Négliger l'historique — il trace toutes les modifications
